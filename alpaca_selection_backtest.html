📊 Coin selection backtest →

What this measures: for each stock/ETF prop_bot.py and alpaca_swing_bot.py are eligible to trade — SPY, QQQ, DIA, IWM, GLD, USO, SLV, plus the 1x inverse ETFs SH/PSQ/DOG/RWM — this pulls real historical 15-minute bars from Alpaca and simulates buying/selling using the exact same rules the live bot uses (RSI < 40 entry, +2% target, -1.5% stop, breakeven ratchet, 0.5% peak-profit giveback), then ranks them by what that strategy would actually have returned. Long-only: shorting is disabled on the real account, so a short-side backtest would be purely hypothetical. This does not change what the live bot buys; it's a read-only report.
New: the live bot now concentrates on its real top performers. Rather than spread new entries evenly across every symbol above, prop_bot.py now only opens new positions in the top 5 (of 11) symbols by latest real backtested ROI — the same idea the crypto side already uses to lean on its strongest coins instead of diluting real gains across weak ones. A symbol that falls out of the current top 5 shows "Excluded - outside the current top 5 by real backtested ROI" in the Right Now column below; it's not permanent, it re-ranks live every time this backtest runs.
Would looser exit rules have made more real money? The live bot force-closes any position that's ever shown a profit the moment it gives back 0.5% from its best point - tight profit protection, but it may also be why gains stay small even when a trade is genuinely trending. This replays the exact same real historical bars above under 3 exit-rule scenarios side by side (using the bot's own real should_exit_position() for each), so you can see the real trade-off instead of guessing.
What if it bought strength instead of weakness? Everything above buys the dip (RSI oversold) and takes a small quick profit. This replays the exact same real historical bars under the opposite idea — buy a symbol already showing real momentum (RSI > 55, price above its own 20-bar average) and ride it with a trailing stop off its peak instead of a small fixed target. Same real data, a genuinely different rule set, side by side.
Was that result a fluke, or does it hold up? A single 30-day window can flip either way by chance - the same "require several consecutive results, not one" rule the crypto side's auto-exclusion already uses. This re-runs the exact same real momentum-vs-mean-reversion replay across 3 separate, back-to-back real 30-day windows (the real last ~90 days) and reports how many of the 3 each strategy actually won, not just one sample's total.

Switch the live strategy family:

A real, reversible switch (not a one-way code change) between the two whole real rule sets - momentum's own entry variant (A/B/C/D above) only applies while momentum is live. Takes effect on the bot's very next cycle.

Would running BOTH strategies together make more money? The comparison above tests each ruleset independently, each with its own always-available $150/trade — the right way to see which one's better, but not the right way to see what happens with real shared cash. This merges the same real bars onto one real timeline and runs both entry gates against a single pool at once, so a strong signal on one symbol can genuinely compete with a strong signal on another for the same real dollars — showing both a realistic number (a modest real shared pool) and the theoretical ceiling (unlimited capital).
Is RSI > 55 + price > SMA20 too binary? It can spot momentum, but it can't tell a fresh breakout from a stock that's already run hard and is due to snap back. This tests 4 entry variants that progressively add real filters — B adds "RSI rising" (not just above 55), C adds "SMA20 rising" too, D adds a cap on how far price can already be above SMA20 — with the exit rule held exactly the same across all four, so this isolates entry quality specifically. Judges on more than total profit: win rate, profit factor, max drawdown, Sharpe/Sortino, average holding time, and longest losing streak.
