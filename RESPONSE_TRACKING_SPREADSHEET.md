## 🎯 RESPONSE TYPES TO EXPECT

### Type 1: "Not Interested"
```
Response: "Thanks but not a good fit right now"
Action: Save for 30-day follow-up
Tracking: Mark Response? = YES, Interested? = NO
```

### Type 2: "Tell Me More"
```
Response: "How does this work?" or "Sounds interesting"
Action: Send demo/call scheduling email immediately
Tracking: Mark Response? = YES, Interested? = YES
```

### Type 3: "Yes, Let's Try"
```
Response: "Let's set up a call" or "Can you show me?"
Action: Schedule 15-min demo/integration call
Tracking: Mark Response? = YES, Interested? = YES, Call? = YES
```

### Type 4: "Silent"
```
No response within 7 days
Action: Send follow-up email #2
Tracking: Response? = NO (remains checked for 7 days)
```
